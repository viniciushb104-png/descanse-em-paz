# Lote 05 — Arredores da estrada

Instale os oito sprites WebP com transparência: lamp.webp, tree.webp, pumpkins.webp, fence.webp, mausoleum.webp, house.webp, vegetation.webp, ghost.webp. O minigame detecta automaticamente os arquivos e usa os recursos existentes quando algum estiver ausente. O indicador HD mostra quantos dos oito sprites novos foram carregados. As imagens devem manter proporções originais e margem transparente mínima.
