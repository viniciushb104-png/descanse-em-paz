# Artes horizontais da revista V2
Envie os arquivos WebP preparados sem alterar nomes. O carregamento é automático.

- capa_dupla.webp: abertura do catálogo.
- amalia_dupla.webp: página 02.
- serenidade_dupla.webp: página 03.
- mesa_de_leitura.webp: fundo fixo, sem controles impressos.
- capa_fechada.webp: alternativa quando a capa dupla ainda não existir.
- contracapa.webp: futura arte definitiva da contracapa (opcional).
- ultimo_suspiro_dupla.webp, descanso_eterno_dupla.webp etc.: páginas comerciais seguintes. Formato horizontal 1672 × 941. Não imprimir preços nas futuras artes, pois os valores são nativos.

Os sprites abertos e tampas continuam nos respectivos diretórios em assets/sprites/coffins. A revista não modifica a capela.
