# Caixões modulares da capela

Cada modelo usa o identificador de `coffin_catalog.gd`.

- `<modelo>/aberto.png`: base vazia, cabeça para cima e pés para baixo.
- `<modelo>/tampa.png`: tampa isolada, sem fundo.
- `<modelo>/borda_frontal.png`: camada opcional com o mesmo enquadramento da base aberta.
- `<modelo>/fechado.png`: reservado para a futura vitrine e animação de fechamento.

Sprites das pessoas homenageadas: `assets/sprites/funeral_people/<sprite>.png`, identificador em `funeral_lore.gd`. As posições de encaixe estão em `chapel_coffin_art.gd`. Modelos sem arte definitiva usam temporariamente o Serenidade com aviso visual, sem alterar o contrato.

Os dois PNGs do Serenidade são derivados das artes aprovadas, reduzidos e com transparência limpa para a escala do jogo.
