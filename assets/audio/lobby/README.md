# Trilha instrumental do mapa de Santa Mortalha

Envie para esta pasta um arquivo `santa_mortalha.ogg` (preferido) ou `santa_mortalha.wav` gerado no Gemini. Não é preciso alterar código.

A trilha inicia no mapa externo (cemitério e acessos), toca em loop, reduz volume nos diálogos e desaparece suavemente ao entrar em interiores ou minigames. Caso nenhum dos arquivos exista, o jogo continua normalmente sem trilha.

Use música original, licenciada para o projeto. Prefira OGG de tamanho moderado para GitHub Pages e dispositivos móveis. Para evitar emendas audíveis, exporte o áudio como loop musical sem silêncio no início ou final.
